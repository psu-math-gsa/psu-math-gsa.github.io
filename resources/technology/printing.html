Printing in McAllister

For all operating systems, make sure you connect to the eduroam network first. VPNs may cause problems when attempting to add printers/print.

Adding printers

This generally requires that your user is a member of the lpadmin group. You can see if you are already a member by running groups $USER in any terminal, which will output your username and all groups you belong to. If you don't see lpadmin listed, run sudo usermod -a -G lpadmin [username] to add [username] to the group. You may need to restart afterwards for the change to take effect.

  1. Go to http://localhost:631/admin/ to access the CUPS utility. If prompted, login using your username or password. You should then see the CUPS administration screen:

  2. Select "Add printer". On the next screen, select "Internet Printing Protocol (ipp)", then hit "Continue".

  3. Type in the address: ipp://[IP address]/ipp/print

  4. Type in a name you will recognize (NOTE: this is hard to change later!). Optionally add a description or location (can be modified later).
  5. Install printer drivers.
    • Option 1: select from preinstalled system drivers.

      1. Select the printer make (Ricoh) from the list, then hit "Continue".

      2. Select the printer model. This is likely IM 5000, but check the specific printer you're adding. You can choose either a PDF or PostScript (PS) driver; PDF may be faster, while PS is theoretically capable of higher image quality. After selecting the driver, hit "Continue".

        If you do not see the correct model, you can use IPP Everywhere drivers, or you can look on Ricoh's site for a .ppd file for the printer and use Option 2 below.

    • Option 2: download a .ppd file for the printer from Ricoh's site, and upload it now.

  6. Hit "Set Printer Options" to install the finisher and set defaults. (This can all be done later as well.)

  7. Add the finisher: on the screen to select default options, select "Finisher SR3260" in the finishers dropdown. (You can check the sticker on the inside of the specific finisher for its model number if selecting SR3260 does not work.)

Managing printers

CUPS can also be used to manage printers, even those added via a system GUI. From the CUPS admin page, hit "Manage Printers" and click on the name of the printer you wish to modify.

  • You can print a test page or stop a current print job using the first dropdown.
  • You can change the printer protocol, description, location, sharing status, or drivers with the "Modify printer" option in the second dropdown.
  • You can change installed options/default behavior with the "Set Default Options" option in the second dropdown:
    • Use the "Options Installed" section to change installed hardware (should only be the finisher) and, if you used a PS driver, PostScript mode.
    • Use "Finishing" to select defaults for one/two-sided printing and stapling/embossing.
  • You can delete a printer.
  • You cannot change the name of a printer here. You may be able to change a printer's name by editing the file /etc/cups/printers.conf but it is likely easier to delete and re-add the printer with the desired name.

Printing via the command line

Many systems provide a printing GUI, which can be accessed with Ctrl + p. However, it is also possible to print from the command line.

To print using the lp System V utility:

  • Use -d [printername] to specify the printer to use. You can also run lpoptions -d [printername] to set [printername] as your default printer.
  • Use -n [number] to print [number] copies.
  • Use -o Duplex=[value] to choose one/two-sided printing. Valid values are None for one-sided prints, DuplexNoTumble for two-sided prints which flip on long edge (more common), and DuplexTumble for two-sided prints which flip on short edge (less common, used with landscape pages).
  • Use -o StapleLocation=[value] to staple. Valid values are UpperLeft, UpperRight, LeftW (two staples on left side), RightW, UpperW for staples, and StaplessUpperLeft and StaplessUpperRight for embossing (up to 5 sheets).

You can also use lpr to print; see its man page for details.

Adding printers

These instructions were developed for the GNOME desktop environment (which is the default on Ubuntu). Other desktop environments such as KDE or Cosmic will likely offer similar graphical user interface options, but if you cannot find the correct options to add a printer/use finishing options then try the CUPS instructions instead.

  1. Search for printers in your system settings (or the apps ), and select the option to add a printer.
  2. Add the printer using IPP (internet printing protocol) by IP address. You will likely have to search for the printer using the IP address (in testing, no printers were discovered automatically).
  3. Select the printer model to install the needed drivers. The black and white printers should be model RICOH IM-5000, but you should check the specific printer you are adding to be sure.
  4. Under "printer options" for the printer you just added, select "installable options" and install the finisher. The black and white printers should have finisher SR-3260 (you can check the sticker on the inside of the finisher if this does not work). This will allow you to staple and use other finishing options.

Adding printers

  1. Download the RICOH print drivers from Ricoh's site. (The department has primarily IM 5000 printers, which use the same drivers as the IM 2500. If you are trying to add a different model of printer, search for the drivers for that printer instead.)
  2. Run the downloaded .dmg file to install the drivers. (You can delete the file after installation if desired.)
  3. Go to System Settings > Printers & Scanners and click "Add Printer, Scanner, or Fax".
  4. Select the IP tab (globe icon), enter the IP address of the printer you wish to connect, give it a name you will recognize later, and click Add.
  5. Click on the printer in the Printers list and click Options & Supplies.
  6. Navigate to the Options tab and select Finisher SR3260 in the Finisher dropdown menu.

Printing

The keyboard shortcut to print on Mac is Command + p.

If you have installed the finisher, finishing options can be found under Printer Options > Printer Features by selecting "Finishing" from the Feature Sets dropdown menu.

Adding printers

  1. In settings, navigate to the printers page (steps vary by version, but you should be able to find it by searching “printer”)
  2. Hit “Add printer manually”.
  3. Add the printer using the Internet Printing Protocol (IPP) and the queue ipp/print
For instructions to add a printer while inside the Crostini development environment, see the Linux CUPS/command line instructions.

Printing

For finishing options when printing (such as stapling), hit “More settings” and then “Advanced settings”. In testing, specialized finishing options were not available. The “Staple” and “Staple top left” options produced the same result.
